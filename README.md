## 🧭 Философия и функциональный триколор

В основу интерфейса заложена идея **функционального триколора**, где национальная палитра выступает строгой навигационной системой, а не декоративным элементом:

- 🤍 **Белый (`#D8DADF`): Ввод данных** — цифры `0–9`, десятичная запятая, смена знака `±`, фундаментальные физические константы.
- 💙 **Синий (`#2E4FB5`): Вычисления** — арифметические операции `+`, `−`, `×`, `÷`, `%`, функции памяти (`M+`, `M−`, `MR`), тригонометрия и акцентная клавиша `=`.
- ❤️ **Красный (`#C0392B`): Управление** — сброс `C`, стирание последнего символа `⌫`, очистка памяти `MC`, переключение режимов и управление ставками.

## ⚡ Режимы работы

1. **Обычный:**
   - 4 базовых арифметических действия, процентные вычисления, регистры памяти ($M+, M-, MR, MC$).
2. **Инженерный:**
   - Тригонометрические функции ($\sin, \cos, \tan$) с переключением единиц угловой меры (`DEG` / `RAD`).
   - Возведение в квадрат ($x^2$), извлечение квадратного корня ($\sqrt{x}$), факториал ($n!$), обратное число ($1/x$).
   - Натуральный ($\ln$) и десятичный ($\lg$) логарифмы.
   - Быстрый ввод мировых и национальных констант: $\pi$, $e$, ускорение свободного падения $g = 9{,}80665\text{ м/с}^2$, скорость света $c_0 = 299\,792\,458\text{ м/с}$, число Авогадро $N_A = 6{,}022\times 10^{23}\text{ моль}^{-1}$.
3. **Финансы РФ:**
   - Расчёт налога на добавленную стоимость (НДС 20%, льготный 10%, экспортный 0%) с функциями начисления («+ НДС») и выделения («в т.ч. НДС»).
   - Ипотечный калькулятор (аннуитетный график, ежемесячный платёж, общая переплата).
   - Депозитный калькулятор с возможностью ежемесячной капитализации процентов.
   - Индикативное табло курсов валют и ключевой ставки ЦБ РФ.
4. **Стройка («Монолит»):**
   - Расчёт кубатуры монолитной заливки бетона с учётом технологического коэффициента усадки и количества автобетоносмесителей («миксеров»).
   - Расчёт чистой площади стен и необходимого количества рулонов обоев с учётом вычета оконных и дверных проёмов.
   - Расчёт напольных покрытий (ламинат, керамогранит) с запасом на подрезку.

## 🎧 Особенности взаимодействия

- **Акустический отклик реле:** Программная имитация щелчков промышленного электромагнитного реле через Web Audio API без использования внешних файлов.
- **Тактильная отдача (Haptic):** Короткие импульсы вибрации при работе с мобильных устройств.
- **Журнал операций:** Выдвижная боковая панель с возможностью мгновенного возврата любого предыдущего результата в табло.
- **Клавиатурное управление:** Полная поддержка Numpad и горячих клавиш (`Enter`, `Backspace`, `Esc`, `+`, `-`, `*`, `/`).
